01 · FEATURE SAFETY

Never call a disabled module

Tabs and feed sources derive from workspace feature access. Cards payment data appears only when both credit cards and card payments are enabled.

02 · SPLIT INTEGRITY

One financial event, one row

A completed split already creates or links an expense. Activity shows that expense once with a Split marker; open splits live in a separate attention module.

03 · OPTIONAL FUTURE API

Unified feed can wait

A paginated activity endpoint would reduce requests at scale, but it is an optimization. The current month can be assembled safely from existing list routes.

Savings correction for the final design:

Replace goal completion bars and deadlines with account balance, share of total, this-month movement, and recurring contribution status. This preserves the visual hierarchy while making every number traceable to the current server.
