Locked system rules

TypographySF Pro system ramp; one display value per screen; tabular numerals for every amount.
GeometryCircles for actions, capsules for navigation, 18pt cards, 12pt fields, 10pt icon containers.
AccentLime only for primary actions, active navigation, focus, and meaningful progress.
ElevationOnly persistent navigation and temporary menus float. Content stays flat and structural.
ThemesSettings: Dark (default), Light, System. Every state ships in both palettes.
Motion language: native push/pop and tab behavior; 100–150ms press feedback; Signature Scanner uses a restrained 300ms spring and one light haptic; no dashboard entrance choreography; Reduce Motion converts spatial transforms to fades.
